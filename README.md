# معرض أعمال مرام

موقع معرض أعمال شخصي (Portfolio) عربي متجاوب، صُمّم ليعرض هوية **مرام** كمطوّرة ومصمّمة مواقع ويب، ويقدّم مشاريعها ومهاراتها ووسائل التواصل معها في تجربة بصرية هادئة وأنيقة.

## فكرة المشروع

الموقع هو مساحة رقمية شخصية تجمع بين التصميم والبرمجة في واجهة واحدة. يعتمد على لغة عربية واضحة، وتخطيط بصري متوازن، وألوان مستوحاة من الأزرق الفاتح، الأبيض العاجي، والبنفسجي الهادئ، مع تفاصيل حركية خفيفة تعطي انطباعاً احترافياً دون مبالغة.

الهدف من الموقع هو تعريف الزائر بالمطوّرة، عرض نماذج من أعمالها، وإتاحة التواصل معها بسهولة لبدء مشروع جديد.

## الأقسام

- **الترحيب:** تعريف سريع بمرام كمطوّرة ومصمّمة مواقع، مع أزرار للتنقل وأرقام موجزة.
- **أعمالي ومشاريعي:** ثلاث بطاقات لمشاريع مختلفة:
  - موقع مطعم بيتزا راف.
  - موقع مقهى روست آند لاين.
  - نظام ذكي لإدارة الشحنات.
  - لكل مشروع زر **معاينة المشروع** يفتح نافذة تفاصيل تفاعلية.
- **مهاراتي:** بطاقات لمهارات HTML وCSS وJavaScript وJava وC# وSQL مع وصف ومؤشر مستوى.
- **تواصل معي:** لوحة تواصل تتضمن البريد الإلكتروني وحالة التوفر وروابط التواصل الاجتماعي.

## الميزات

- تصميم عربي كامل باتجاه RTL.
- متجاوب مع الجوال واللوحي وسطح المكتب.
- شريط تنقل ثابت مع قائمة مخصصة للجوال.
- نوافذ معاينة للمشاريع مبنية باستخدام عنصر `<dialog>`.
- تثبيت الرابط النشط أثناء التمرير.
- استخدام خط Tajawal من Google Fonts مع بدائل محلية.
- دعم تقليل الحركة عبر `prefers-reduced-motion`.
- تحسينات بسيطة لإمكانية الوصول: رابط تجاوز المحتوى، تسميات ARIA، وحالات تركيز واضحة.

## بنية الملفات

```text
.
├── index.html    # بنية الصفحة، المحتوى، ونافذة المعاينة
├── style.css     # التصميم الكامل، الحركات، والتجاوب
└── README.md     # توثيق المشروع
```

## التشغيل

لا يحتاج المشروع إلى أي أدوات بناء أو تثبيت حزم. افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً:

```bash
python -m http.server 5500
```

ثم افتح:

```text
http://localhost:5500
```

## التخصيص

- **الاسم والهوية:** عدّل النصوص داخل `index.html` في شريط التنقل، القسم الترحيبي، والتذييل.
- **البريد الإلكتروني:** استبدل `hello@maram.dev` في قسم التواصل بريدك الفعلي (يظهر في رابط `mailto` أيضاً).
- **روابط التواصل:** استبدل روابط GitHub وLinkedIn وInstagram الحالية بروابط حساباتك.
- **المشاريع:** عدّل عناوين البطاقات وأوصافها ووسوم التقنيات، ومحتوى نافذة كل مشروع.
- **روابط المعاينة:** حالياً تفتح أزرار المعاينة نوافذ تفاصيل داخلية. إذا أصبح لديك رابط حي لكل مشروع، يمكن تحويل الزر إلى رابط `<a>` يفتح المشروع في تبويب جديد.
- **المهارات:** عدّل النسب من خلال `aria-valuenow` وقيمة `--fill` داخل كل بطاقة.
- **الألوان:** جميع ألوان الهوية معرّفة كمتغيرات CSS في بداية ملف `style.css` داخل `:root`.
